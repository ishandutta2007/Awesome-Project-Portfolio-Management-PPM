# Awesome-Project-Portfolio-Management-PPM

# Top Project Portfolio Management (PPM) Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Portfolio Prioritization, Resource Capacity Planning & Strategic Execution*  
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Project Portfolio Management (PPM)**. These tools enable organizations to prioritize investments, balance resources across competing initiatives, and govern project portfolios to ensure alignment with strategic objectives and efficient delivery.

**Examples** include ServiceNow Project Portfolio Management, Planview, Microsoft Project, Asana, Monday.com, Smartsheet, Wrike, ClickUp, Clarizen (Planview AdaptiveWork), and Broadcom Clarity (the category leaders).

**Open-source emphasis**: This section is expanded with active projects for self-hosted portfolio governance, resource planning, and project execution—ideal for PMOs, public sector organizations, and enterprises building sovereign PPM infrastructure without per-seat licensing lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[ServiceNow Project Portfolio Management](https://www.servicenow.com/)**  
  Enterprise PPM on the Now Platform with demand management, portfolio planning, resource management, and financial tracking integrated with strategic goals.

- **[Planview](https://www.planview.com/)**  
  Comprehensive portfolio management platform spanning strategic planning, work management, and resource capacity planning for enterprise PMOs; AdaptiveWork (formerly Clarizen) provides real-time visibility and workflow automation for PMOs and professional services teams .

- **[Microsoft Project](https://www.microsoft.com/en-us/microsoft-365/project/project-management-software)**  
  Established project and portfolio management tool with Gantt charts, resource allocation, and portfolio dashboards; widely adopted in enterprises already within the Microsoft ecosystem.

- **[Asana](https://asana.com/)**  
  Work management platform with portfolio views, goals tracking, and timeline dependencies for cross-team project visibility.

- **[Monday.com](https://monday.com/)**  
  Work OS with portfolio management capabilities, dashboards, and automation for tracking multiple projects and resource allocation.

- **[Smartsheet](https://www.smartsheet.com/)**  
  Spreadsheet-based work management with portfolio rollup reports, resource views, and cross-project dashboards for operational teams .

- **[Wrike](https://www.wrike.com/)**  
  Collaborative work management with portfolio planning, resource management, and custom workflows for marketing and professional services teams.

- **[ClickUp](https://clickup.com/)**  
  All-in-one productivity platform with portfolio views, goals, and resource management for teams seeking to consolidate tools.

- **[Clarizen (Planview AdaptiveWork)](https://www.planview.com/products/adaptivework/)**  
  PPM platform for PMOs and professional services delivery with real-time visibility, workflow automation, and risk management .

- **[Broadcom Clarity](https://www.broadcom.com/products/software/value-stream-management/clarity)**  
  Strategic Portfolio Management solution connecting finance, operations, and delivery for enterprise-wide governance, investment management, and capacity planning .

## Open-Source GitHub Projects

- **[OpenProject](https://github.com/opf/openproject)**  
  Leading open-source web-based project management and PPM platform (GPL-3.0); supports project planning, Gantt charts, Agile workflows, time tracking, and **project portfolio management**; deployable on-premises or via EU-hosted Enterprise Cloud with GDPR compliance, BSI IT-Grundschutz alignment, and WCAG 2.1 accessibility .

- **[LibrePlan](https://github.com/LibrePlan/libreplan)**  
  Open-source web-based project management platform (AGPL) focused on **project and portfolio planning**, resource allocation, capacity management, issue and risk tracking, and project governance; designed for self-hosted and sovereign cloud deployments; v1.6.0 adds issue/risk logs, project document repositories, and expanded translations .

- **[Plane](https://github.com/makeplane/plane)**  
  Modern open-source project management platform (AGPL-3.0) positioned as an alternative to Jira, Linear, Monday, and Asana; features work items, cycles (sprints), modules, pages, and five layout views (List, Board, Spreadsheet, Gantt, Calendar); self-hostable with 47,800+ GitHub stars .

- **[ProjectLibre](https://www.projectlibre.com/)**  
  Open-source desktop project management tool compatible with Microsoft Project files; provides Gantt charts, earned value costing, PERT charts, WBS, and resource allocation; suitable for traditional plan-driven project portfolios .

- **[Taiga](https://github.com/taigaio/taiga)**  
  Agile project management platform (GPL-3.0) with Scrum and Kanban boards, issue tracking, and multi-project views; suitable for agile-heavy portfolios requiring sprint and epic management .

- **[Vikunja](https://github.com/go-vikunja/vikunja)**  
  Lightweight open-source task management tool (AGPLv3) with Kanban, Gantt, List, and Table views; self-hosted or managed cloud; ideal for small teams seeking simplicity and data ownership over complex PPM features .

- **[Grist](https://github.com/gristlabs/grist-core)**  
  Open-source spreadsheet-database hybrid with PPM capabilities through relational data, dashboards, and automation; self-hostable with portable SQLite files for data ownership; positioned as a Smartsheet alternative for connected project data .

- **[Kan.bn](https://github.com/kanbn/kan)**  
  Open-source kanban platform (AGPL-3.0) for team collaboration with board visibility controls, Trello import, and self-hosting; suitable for lightweight project tracking within a portfolio .

### Additional Strong Open-Source Options

- **Paca** — AI-native open-source project management platform (Apache-2.0) with Scrum boards, sprints, and MCP server for AI agent collaboration; self-hosted via Docker or Kubernetes .
- **Huly** — Open-source all-in-one workspace (EPL-2.0) combining project management, documents, and team chat for development teams .
- **Kaneo** — Open-source project management with kanban boards, timelines, and automation (MIT) for lean teams .

**Frameworks for building custom systems**: Combine **OpenProject** for full portfolio governance with Gantt-based planning, **LibrePlan** for resource-constrained capacity management, **Plane** for modern agile execution, and **Grist** for connected project data and dashboards in a fully self-hosted PPM stack.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- PPM platforms handling financial and strategic data must comply with applicable regulations and organizational governance policies.
- Self-hosted open-source solutions vary in PPM depth—OpenProject and LibrePlan offer portfolio-level planning, while Plane and Vikunja are stronger for project execution than strategic portfolio governance.
- Verify license terms for commercial use; OpenProject uses GPL-3.0, LibrePlan uses AGPL, Plane uses AGPL-3.0, and Grist uses a custom open-source license.
